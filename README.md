# GitHub 热门项目周刊自动化工作流

基于 Codex Skill 的中文开源项目周刊制作流程，串联选题、资料核实、写作、AI 配图与飞书图文交付。仓库提供 Skill 和本地打包脚本，联网检索、图片生成及飞书操作由运行环境提供。

## 制作流程

读取 GitHub Trending 周榜 → 按累计 Star 筛选 5 个候选 → 核实官方资料 → 撰写推荐 → 生成 3 张配图 → 检查排版 → 创建飞书文档或交付本地文件。

每个项目介绍用途与具体优势、适用人群与场景、官方地址及上手难度。正文固定以“Hello，大家好！”开头，以“记得点赞、收藏、关注。”结尾。图片标明为 AI 概念插画，不冒充产品截图。

## 目录

```text
SKILL.md                      # 工作流与交付检查要求
agents/openai.yaml            # Skill 展示信息与默认提示
references/editorial.md       # 写作、配图提示及 JSON 数据格式
scripts/package_article.py    # 仅用 Python 标准库打包本地图文稿
docs/automation.md            # 定时任务配置提示与运行条件
```

## 在 Codex 中使用

1. 克隆仓库，将整个目录放入本机的 Codex skills 目录，并命名为 `github-weekly`。
2. 确保运行环境具备联网检索和图片生成能力。原生飞书文档需要另行安装官方飞书 CLI 或可用连接，并在自己的设备上完成授权。
3. 在 Codex 中调用：

```text
用 $github-weekly 制作本周 GitHub 热门项目推荐，选 5 个项目，核实官方资料，生成配图并排成飞书图文稿。
```

Skill 是供智能体执行的说明，不是运行 Python 后就能自动检索和发布的独立程序。它可单独执行；定时运行需在 Codex 中另行配置，见 [定时任务说明](docs/automation.md)。

## 本地打包

Python 3.10+，不需要安装第三方 Python 包。先准备已核实的文章 JSON 与 3 张图片，数据结构见 [写作参考](references/editorial.md)。

```bash
python scripts/package_article.py article.json --out outputs/2026-10-28
```

输出为：

- `article.html`：内嵌图片的自包含网页。
- `article.md` 与 `images/`：正文和图片文件。
- `feishu-article-assets.zip`：素材包。
- `image-prompts.txt`：输入中提供生成说明时保存。

脚本校验 5 个项目、3 张图片及 GitHub 地址，自动插入固定开头和结尾，并拒绝写入非空输出目录。脚本不联网、不生成图片、不发布飞书；成功退出后仍应检查实际图文排版。

## 飞书与凭据

使用个人环境中配置的飞书连接或官方 CLI，授权信息由官方工具管理。CLI 路径需按本机安装位置查找，使用用户身份操作，并在创建文档后回读检查。

本仓库不包含飞书凭据、API Key、授权二维码或个人云文档链接。请勿提交 `.env`、CLI 配置、访问令牌、授权日志和个人生成物。`.gitignore` 只提供基础排除规则，不能代替提交前检查。

## 已验证与限制

- 已完成一期 5 个项目、1 张封面及 2 张正文插画的周刊，交付过本地图文素材包和原生飞书文档。
- 已配置本地每周定时任务；曾出现触发延迟与图片生成网络错误，目前未验证稳定的无人值守运行。
- 本地定时任务依赖电脑开机、Codex 运行、网络可用及飞书授权有效。
- 项目资料与 Star 数需要每期重新查询。无法核实的数据不应沿用旧值。
- 当前未实现脚本级自动重试、异常通知服务或云端调度。
