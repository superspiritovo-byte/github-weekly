# 定时运行

在 Codex 中创建每周五 18:00（Asia/Shanghai）的本地定时任务，并指向已安装的 `github-weekly` Skill。本仓库不包含个人自动化配置文件。

任务提示可使用：

```text
执行本地 $github-weekly，每期重新读取 GitHub Trending 周榜作为候选，按累计 Star 选出 5 个项目，核实官方资料，不沿用旧榜单。遵循 Skill 的写作与配图标准，生成封面和两张正文插画，检查排版。

按 Asia/Shanghai 日期创建独立输出目录。有可用飞书连接时创建并回读原生文档，提供真实链接；无连接时交付自包含 HTML、Markdown 与图片素材包，明确说明未创建原生飞书文档。完成时提供成品；失败时说明具体原因和所需操作。
```

本地运行时保持电脑开机、Codex 运行、网络可用及飞书授权有效。将窗口最小化不影响这一要求，退出应用或电脑睡眠会影响执行。

每次运行应检查查询时间、图片生成结果、输出文件与飞书回读结果。定时配置本身不代表执行成功；当前流程尚未验证稳定无人值守运行，失败重试与独立异常通知仍待完善。
